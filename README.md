# Estructura de Datos

Trabajos y ejercicios de la materia **Estructura de Datos**, desarrollados en **Java** con Eclipse.

Instituto Tecnológico de Jiquilpan (TecNM) — Ingeniería en Sistemas Computacionales.

## Contenido

El código está organizado por temas dentro de la carpeta `src/`:

- **tema1** — Repaso: arreglos, matrices, registros y vectores dinámicos.
- **tema2** — Recursividad: factorial, potencia, sumas y productos recursivos.
- **tema3** — Estructuras lineales dinámicas: listas (simple, doble y circular), pilas, colas y bicolas.
- **tema4** — Estructuras no lineales: árboles y grafos.
- **tema5** — Métodos de ordenamiento (interno y externo).
- **tema6** — Métodos de búsqueda y tablas hash.

## Tecnologías
